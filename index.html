Linux Mint Backup - rclone

Linux Mint Backup - rclone is a privately operated, noncommercial backup configuration used to protect personal files on a Linux Mint computer.

Purpose

The configuration uses rclone to connect to Google Drive and Restic to create encrypted, versioned backups.

How It Works

Restic encrypts backup contents locally before they are uploaded to Google Drive through rclone. The backup system is operated by the account owner and is not offered as a service to other users.

Google Drive Access

The application requests Google Drive authorization to create, read, update, and manage backup files. Access is used solely for the account owner's personal backup and recovery operations.

Privacy

For information about data handling and Google Drive permissions, please read the Privacy Policy.

This is an independent personal backup configuration. It is not affiliated with Google, rclone, Restic, or the Linux Mint project.
