Privacy Policy

Last updated: November 2, 2026

1. Overview

Linux Mint Backup - rclone is a privately operated, noncommercial backup configuration used by its owner to protect personal files.

2. Google Drive Access

The application uses OAuth authorization through Google's APIs to access the owner's Google Drive account. Authorization is used to create, read, update, organize, and delete files as necessary for personal backup and recovery operations.

The configured Google Drive permission may allow access to other files in the authorized account. The application is intended to operate only on backup locations selected by the owner.

3. Data Processing and Storage

Restic encrypts backup contents locally before they are uploaded to Google Drive through rclone. The backup repository is stored in the owner's Google Drive account.

Authentication credentials are maintained locally for the owner's backup configuration.

4. Data Sharing

The backup configuration is not offered to third parties. It does not intentionally transfer personal backup contents to third-party recipients beyond the storage and authentication services necessary for operation.

Google processes information according to its applicable terms and privacy policies.

5. Data Retention and Deletion

Backup files are retained according to the owner's backup and retention settings. The owner can delete stored backups and revoke Google Drive authorization.

6. Website Data

This website does not contain application-specific analytics scripts, advertising trackers, or forms collecting visitor information.

The website is hosted by GitHub Pages, which may process technical information associated with visits according to GitHub's own policies.

7. Security

Backup contents are encrypted using Restic. Access to the backup repository and its credentials is controlled by the account owner.

8. Contact

Questions about this personal backup configuration can be submitted through the GitHub account associated with this website .
